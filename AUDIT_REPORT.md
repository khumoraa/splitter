## 5. Мои правки вне аудита (аудит был «только чтение») и почему они безопасны для фронтенда

Они были разрешены вашим подтверждением плана (шаги 1–4), но шаги 1–4 прямо не описывали каждую из них:

| Правка | Почему безопасна для фронта |
|---|---|
| `GET /users/:id` требует токен | фронт этот маршрут не вызывает (grep по `app/` и `src/`: только `/users/me/avatar`); интерцептор и так шлёт токен |
| `/debug/*` за токеном, не в production | фронт `/debug` не вызывает |
| `GET /sessions?groupId=` → 403 для не-членов | при открытии группы пользователь — её член/владелец, а проверка допускает обоих. **Риск:** не проверено запуском на стороне члена; если фронт запрашивает сессии чужой группы, получит 403 |
| Удалены `console.log` с телом запроса | только логи, API-ответы не меняются |
| `listen("0.0.0.0")` | расширяет доступ по сети (нужно для телефона); API то же. Минус: сервер виден всей локальной сети |
| Дефолт API `:3000`→`:3001`, таймаут 500→60 с | только клиентский конфиг; медленный OCR-запрос свыше 60 с теперь оборвётся — **риск**, если Gemini отвечает дольше (при необходимости увеличить для `/sessions/scan`) |
| Поле `currency?` в типах истории | чисто типы, на рантайм не влияют |
| `avatarUrl` + `as any` в группах | в `[groupId].tsx` кандидатам теперь передаётся `avatarUrl` (раньше был `undefined`), может появиться аватар вместо инициалов; `as any` ослабляет типизацию — временное решение |
| `npx expo install --fix` | поднял `expo` до `~54.0.37` и ещё ~13 пакетов в рамках SDK 54 (патч-версии), `package-lock.json` пересобран. Это ровно версии, совместимые с Expo Go 54, но это обновление зависимостей **шире, чем «правка конфигов»**; откат невозможен без git |
| `app.json`: добавлены плагины `expo-font`, `expo-localization`, `expo-secure-store` | дописал Expo CLI при `install --fix`/`export`, не я вручную. Плагины штатные для этих пакетов; в Expo Go поведение не меняют |
| Созданы `.env` (оба проекта) | в `.gitignore`; `.env` фронта содержит LAN-IP `192.168.25.32` — при смене сети нужно обновить |
| Установка Node и PostgreSQL в `~/.local` | вне проекта, без sudo, удаляются удалением папок; БД слушает только `127.0.0.1`, пароль `***REMOVED***` — локальный dev |
