# Профиль и настройки: аудит и дизайн-спецификация

Ветка `feature/profile-settings` (от `upgrade/sdk-57`). Expo Go SDK 57, Tamagui, expo-router.

## 1. Что есть / что сломано / чего нет (до переработки)

| Область | Состояние | Деталь |
|---|---|---|
| Профиль (экран) | есть, но громоздкий | `app/tabs/profile.tsx` 896 строк: одна длинная форма (аватар, поля, пароль, выход), свои копии валидации |
| Настройки (экран) | **недостижим** | `app/tabs/settings.tsx` есть, но ни один экран на него не ссылается (`router.push('/tabs/settings')` нигде нет) |
| Загрузка аватара, сервер | сломано без R2 | `/uploads/avatar` без ключей R2 отдаёт 503; хранилища для dev нет |
| Загрузка аватара, клиент | риск | `uploadAvatar` задаёт `Content-Type: multipart/form-data` вручную без boundary → на React Native запрос может уйти без границы |
| Проверка файла | слабая | тип определяется по заголовку `mimetype`, лимит 2 МБ, превышение лимита multer → 500 вместо 413, имя `avatars/<id>/v<ts>/…`, старый файл не удаляется |
| `avatarUrl` без аватара | непоследовательно | `/users/:id`, `DELETE /users/me/avatar`, `/friends`, `/friends/search` подставляют placeholder `placehold.co`; `/auth/me`, группы отдают `null` |
| Сброс аватара | исправлено ранее | после `DELETE /users/me/avatar` клиент берёт `/auth/me` (проверено) |
| Смена имени | частично | сервер: 2–32 символа, без проверки символов |
| Смена email | **небезопасно** | `PATCH /user/email` не требует пароль |
| Смена пароля | есть | правила как при регистрации, требует текущий |
| `PATCH /user/update` | **дыра** | меняет пароль **без** текущего пароля |
| `GET /user/list` | **утечка** | любой авторизованный видит email всех пользователей |
| Удаление аккаунта | сломано | `DELETE /user/delete` без пароля и падает на внешних ключах (500) |
| Токен удалённого пользователя | дыра | `authenticateToken` не проверяет, что пользователь существует |
| Rate limit | нет | ни на загрузке, ни на смене пароля |
| Тема | не работает | `theme` в сторе есть, но `TamaguiProvider` жёстко `defaultTheme="light"` |
| Язык | работает | переключатель в сторе + `I18nProvider`, выбор сохраняется |
| Валюта по умолчанию | нет | `'UZS'` зашита в `receipt-session.store` и в нескольких форматтерах |
| Face ID / Touch ID | **невозможно в Expo Go** | документация Expo: Face ID на iOS в Expo Go не поддерживается (нужен development build) → пропущено |
| QR профиля, поделиться, экспорт данных, хаптики | нет | |
| О приложении, лицензии, политика, обратная связь | нет | |

## 2. Решения

- **Без миграций БД.** Всё хранится существующими полями. Настройки (тема, язык, валюта по умолчанию) — локально (`zustand/persist` → AsyncStorage).
- **Хранилище аватаров** с интерфейсом `AvatarStorage`: R2, если заданы ключи, иначе диск `uploads/avatars/` (в `.gitignore`), отдаётся статикой по `/media/avatars/<uuid>.<ext>`; URL строится от адреса запроса (или `PUBLIC_BASE_URL`), поэтому открывается с телефона по LAN.
- **`avatarUrl` — `string | null`.** Placeholder нигде не отдаётся; на клиенте рисуются инициалы на цветном фоне (цвет детерминирован от `uniqueId`).
- **Face ID**: пропущен (Expo Go), раздел «Безопасность» содержит смену пароля и выход со всех действий-подтверждений.
- **Экспорт данных**: `GET /users/me/export` → JSON (профиль, друзья, группы, история) → файл через `expo-file-system` + системное меню `expo-sharing`.

## 3. Структура экранов и навигация

```
Профиль (/tabs/profile)            ← аватар в шапке приложения
 ├─ Редактировать профиль (/tabs/profile-edit)     аватар (галерея/камера/удалить), имя
 ├─ QR и «Поделиться» (/tabs/profile-qr)
 └─ Настройки (шестерёнка) (/tabs/settings)
      ├─ Аккаунт:     Имя → profile-edit · Email (/tabs/settings-email) · Пароль (/tabs/settings-password)
      │               Выйти (подтверждение) · Удалить аккаунт (/tabs/settings-delete, опасная зона)
      ├─ Внешний вид: Тема — Системная / Светлая / Тёмная (встроенный выбор, применяется сразу)
      ├─ Язык:        EN / 日本語 / O'zbek (/tabs/settings-language)
      ├─ Расчёты:     Валюта по умолчанию (/tabs/settings-currency)
      ├─ Данные:      Экспорт моих данных
      └─ О приложении (/tabs/about): версия/сборка, Политика, Условия, Лицензии (/tabs/legal?doc=…), Обратная связь (mailto)
```

## 4. Токены

Файл `src/shared/ui/tokens.ts`. Контраст пар «текст/фон» проверяется тестом (WCAG AA, ≥ 4.5:1 для обычного текста, ≥ 3:1 для крупного и иконок).

| Токен | Светлая | Тёмная |
|---|---|---|
| `screen` (фон экрана) | `#F2F3F5` | `#0D0F0E` |
| `surface` (карточка) | `#FFFFFF` | `#1A1D1C` |
| `text` | `#111413` | `#F3F5F4` |
| `textMuted` | `#5B6360` | `#A3ABA8` |
| `border` | `#E2E5E4` | `#2C312F` |
| `accent` (иконки, графика) | `#2ECC71` | `#2ECC71` |
| `accentStrong` (залитые кнопки, текст на фоне — белый) | `#17803F` | `#1E9A52` |
| `danger` | `#C62F34` | `#FF6B70` |

Типографика (динамический размер шрифта включён, `allowFontScaling`): заголовок экрана 28/34 bold, раздел 13 uppercase muted, строка 16, подпись 13. Отступы 4/8/12/16/24; радиусы: карточка 16, поле 12, кнопка 14, аватар — круг; тень карточки в светлой теме `0 1 2 rgba(0,0,0,.06)`, в тёмной — граница 1px.

## 5. Состояния

- **Загрузка:** скелетон на карточке профиля, индикатор на кнопках (кнопка заблокирована, повторное нажатие игнорируется), прогресс загрузки аватара в процентах.
- **Пусто:** аватар → инициалы; статистика → «0».
- **Ошибка:** текст на языке пользователя + «Повторить»; сетевой баннер офлайна общий для приложения.
- **Разрешения:** отказ → экран/карточка с объяснением и кнопка «Открыть настройки».
- **Оптимистичность:** только смена темы/языка/валюты (локально, мгновенно). Сетевые операции (имя, email, пароль, аватар) — с откатом: значение в сторе меняется после успешного ответа сервера.

## 6. Анимации

reanimated: появление карточек (fade+translate, 180 мс), нажатие строк (scale 0.98), успех (галочка). При включённом «Уменьшить движение» (`AccessibilityInfo.isReduceMotionEnabled` / `useReducedMotion`) анимации отключаются. Хаптики (`expo-haptics`): успех/ошибка/выбор.

## 7. Доступность

Каждый интерактивный элемент: `accessibilityRole`, `accessibilityLabel`, зона нажатия ≥ 44×44, состояние (`selected`, `disabled`, `busy`). Поля: `textContentType`/`autoComplete` (`username`, `emailAddress`, `password`, `newPassword`), `returnKeyType` + переход фокуса, `KeyboardAvoidingView`, прокрутка к активному полю, safe areas.

## 8. Решения, требующие выбора владельца

См. финальный отчёт: политика конфиденциальности и условия (тексты-заглушки), адрес обратной связи, удаление аккаунта (анонимизация чужой истории), ключи R2 для production, отзыв токенов при смене пароля (нужно поле в БД), Face ID (только dev-сборка).
